### js-overhead page:
This page acts as overhead for all pages and allows easy access across the site.
It has some functionality as well, handling things you could want to add to any page. Mainly items remaining fixed on the screen.

**Parameters:**

[in] **id:** js-overhead

For Box in Grid:

[in] **id:** js-fixed-grid

[in] **data-config:** pos_x, pos_y, width, height

Overhead grid size is 12x6.

Currently only supports one box.
